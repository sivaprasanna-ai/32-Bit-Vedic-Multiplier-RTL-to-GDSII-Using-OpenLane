# 32-Bit Vedic Multiplier RTL-to-GDSII Using OpenLane

A complete open-source RTL-to-GDSII implementation of a hierarchical
32-bit Vedic multiplier using SystemVerilog, Yosys, OpenLane,
OpenROAD, SKY130A and KLayout.

The project covers:

- Hierarchical RTL design
- Functional RTL simulation
- GTKWave waveform verification
- RTL synthesis
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Global/detailed routing
- Power Distribution Network (PDN)
- Static Timing Analysis (STA)
- Power analysis
- IR-drop analysis
- DRC verification
- LVS verification
- Antenna analysis
- Final GDSII generation
- GDSII inspection using KLayout

---

## 1. Project Overview

This project implements a 32-bit × 32-bit Vedic multiplier with
a hierarchical architecture based on smaller multiplier blocks.

The multiplier hierarchy is built using:

- 2-bit Vedic multiplier
- 4-bit Vedic multiplier
- 8-bit Vedic multiplier
- 16-bit Vedic multiplier
- 32-bit Vedic multiplier

The top-level module adds input and output registers around the
32-bit multiplier to provide a synchronous interface.

### Top-Level Interface

| Signal | Width | Description |
|---|---:|---|
| `clk` | 1 | Clock |
| `rst_n` | 1 | Active-low asynchronous reset |
| `a` | 32 | Multiplicand/input A |
| `b` | 32 | Multiplier/input B |
| `product` | 64 | Registered multiplication result |

Known Limitations

This repository represents the completed baseline RTL-to-GDSII
implementation.

The design successfully produced a final GDSII and passed DRC and LVS,
but the baseline physical implementation is not completely closed
for every signoff condition.

Known issues include:

7 antenna violations
Negative worst-case setup slack in multi-corner analysis
Maximum fanout violations in the reported MCSTA analysis
Maximum slew violations in the reported MCSTA analysis

These are retained and documented rather than being hidden from the
project results.

Potential future optimization work includes:

Timing optimization
Fanout optimization
Slew optimization
Antenna repair
Area/power optimization
Comparison of baseline and optimized implementations
